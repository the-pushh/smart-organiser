# Smart Organiser demos

Three silent recordings of real workspace setups, with the external display on the left and the MacBook display on the right. The coding and research clips are 50 seconds each; the guitar clip is 38 seconds. Only the beginning/end were trimmed; the setup sequence runs at its recorded speed.

1. [Writing a feature](01-writing-a-feature.mp4): asks to code a Swift feature in this repo. Opens the smart-organiser folder in VS Code and Apple documentation in Arc.
2. [Memory graphs in AI agents](02-memory-graphs-research.mp4): opens relevant research searches and a fresh TextEdit document, with browser windows tiled across the main display.
3. [Practicing guitar](03-practicing-guitar.mp4): requests a blues backing track and chord references, with Vibe enabled.

The prompt disappears on Enter while planning and setup continue in the background. The agent selected the pages and layout during each recording. The coding demo leaves VS Code in its existing Restricted Mode.

These runs preserve existing apps with close-confirmation dialogs. Some browser window sizes can still trigger a partial-placement warning; the recordings show the actual resulting layouts. Web pages can restore additional windows according to browser behavior. Guitar playback is not automated, and these recordings contain no microphone or system audio.
